# Site Luzion Energia

Site institucional estático (HTML + CSS + JS, sem build) da Luzion Serviços e Soluções em Energia Ltda.

- `index.html`: página única
- `assets/`: fotos e logos

Publicado pelo GitHub Pages a partir da branch `main`.

Se uma alteração não aparecer no site, o GitHub Pages pode ter pulado a publicação: um novo commit na `main` dispara outra.
